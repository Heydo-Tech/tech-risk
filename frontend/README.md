# Repo analysis dashboard

This Vite/React frontend follows the Heydo Apni Mandi design system from
`theme.apnimandi.us`: token-based Mandi Green, Haldi and Board surfaces, Anek
Latin + Bricolage Grotesque typography, visible dark mode, keyboard focus, and
disabled repository exceptions.

Run locally with:

```bash
npm install
npm run dev
```

The current data is deliberately local demo state. The repository manager and
report views are ready to be connected to the GitHub onboarding and PostgreSQL
API next.
